# Mini Gemini CLI

A simplified implementation of Gemini CLI for learning purposes.

This project follows the [Learning Framework](../LEARNING_FRAMEWORK.md) and implements the core concepts of Gemini CLI in ~750 lines of code (vs 8,000+ in production).

## Purpose

Learn by building:
- Gemini API integration
- Function calling (tools)
- Agentic orchestration loops
- Event-driven architecture
- Terminal UI with React/Ink

## Setup

```bash
npm install
```

## Usage

```bash
# Build
npm run build

# Run
npm start
```

## Architecture

See [LEARNING_FRAMEWORK.md](../LEARNING_FRAMEWORK.md) for detailed explanation of each phase.
